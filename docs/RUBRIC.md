# Judging rubric: Code for a Billion (theme: Timely Justice, Legal Backlog)
Score out of 100, four criteria at 25% each:
1. Size of the problem: how many citizens face it (credible source or estimate).
2. Severity: human suffering or economic loss, in numbers.
3. Quality of the solution: how well designed, how effective at solving the problem.
4. Proven impact: real deployment data (users reached, outcomes, before/after).
Ties break on Proven impact, then Size. Eligibility: built using AgentFoundry (AF); public GitHub repo with working README; demo link; submission issue before deadline.
Theme scope: case triage, document summarisation, legal aid access, court scheduling efficiency.
